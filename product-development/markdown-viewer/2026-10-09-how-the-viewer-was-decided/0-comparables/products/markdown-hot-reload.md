## V15 Network and data leaving (multi)

> No network access. The window blocks every outgoing request, so a document renders the same way with the network disconnected.  [1] <https://snapcraft.io/markdown-hot-reload>
> It never contacts the network, because its webview's Content-Security-Policy sets connect-src 'none'.  [2] <https://mhr.chairulakmal.com>
> It opens no port, reaches no network, and never writes to the file  [3] <https://github.com/chairulakmal/markdown-hot-reload>
