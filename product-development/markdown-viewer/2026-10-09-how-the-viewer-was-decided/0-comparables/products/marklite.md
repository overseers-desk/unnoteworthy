## V08 Product kind

> MarkLite is an open source, lightweight Markdown Viewer and Editor for Linux. I wrote MarkLite out of frustration at having to load a feature-heavy Markdown editor to view or make a quick change.
From https://marklite.app:
> MarkLite is a lightweight and fast Markdown viewer/editor for Linux and Windows. When launched or when a file is opened, it opens in viewer mode. You can either read the Markdown document and then close it or simply click the Edit button to edit it. Edit mode is a full-featured editor with features like Find & Replace, Goto Line, Line Numbers, Syntax Highlighting, and Key Commands.
