# The program

- One Tcl script of 263 lines on Tcl 9 and Tk, launched by `wish9.0` with one argument, a file path. No other arguments, no settings file, no state kept between runs.
- Two vendored modules, streamdoc 1.3 and tkdown 2.1, each one `.tm` file under MIT, published in teatotal, the operator's own module repository, with a man page, tests and a demo each. The maker of the modules is the operator, so a form of markdown the viewer lacks is fixable upstream by the same hands, and the vendoring rule in this repository's `CLAUDE.md` governs how a new release lands.
- What tkdown parses, in its own words: fenced code, blockquotes, GFM pipe tables, ATX and setext headings, thematic breaks, image lines, nested lists, links, code spans and asterisk emphasis, "and leaves the rest as literal text"; it "is not a full CommonMark implementation". Reference-style link definitions resolve across the whole document. A footnote label is left as written. Raw HTML, maths and diagrams are outside the stated coverage.
- What the viewer does with it, read from the code: one window, one document; a region per heading; a click on a heading folds its section and the deeper headings under it; fold-all leaves the headings as a table of contents; a find bar (streamdoc's) reaches text in folded sections and table cells and opens the section a hit sits in; tables are grids of wrapping cells fitted to the pane width; a link with a URL scheme is handed to `xdg-open`, a relative markdown path opens in the same window, a `#anchor` scrolls to the heading by GitHub's slug rule; an image path relative to the file is loaded in whatever format Tk reads and its alt text stands in otherwise; F5 reloads from disk keeping the folds by heading title and the scroll position; Ctrl-O opens a file dialog filtered to `.md` and `.markdown`; the prose margin follows the pane width around a ninety-em measure; colours are fixed in the code, light.
- What it does not do, read from the code: edit; watch a file for changes (reload is a keypress); open more than one document; export, print or copy as anything; remember recent files; take options; theme; render maths, diagrams or raw HTML.
- Platform facts: it runs wherever Tcl 9 and Tk are installed. The link call is `xdg-open`, which exists on Linux desktops and not on macOS or Windows, so on those systems a scheme link fails in the shell call as the code stands. Tested by the maker on Linux only, as far as the repository records.
- Packaging in this repository: none. There is no LICENSE file, README, icon, desktop entry, man page, test, installer or release. The GitHub repository is public under the operator's account with a placeholder name and a 2019 description of a different program, seven commits, all of 2026-10-09.
