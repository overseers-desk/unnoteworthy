# Coding clerk

Read `briefs/standing-brief-block.md` first, then `0-comparables/codebook-v1.md`, then the profiles the launch message assigns you under `0-comparables/products/`. Nothing else in the repository is open to you: not the frame, not the lists, not any page on the web. You code from the profile's quoted text and from nothing else.

Apply the frozen codebook to each profile and write `0-comparables/coded/<shard>.tsv`, the shard name given in the launch message: one row per product, one column per codebook variable in the codebook's order, with a first column for the product slug and a last column "notes" for anything the codebook told you to note. Text only; silence in the profile is the value the codebook gives for silence, not a fact about the product; no inference in either direction. Where a rule cannot decide a case, code it as the codebook says and note the case; extend no rule.

Your final message gives the count of rows written, the variables you found hardest to apply with the cases that made them so, and every case you coded as undecidable.
