# Priors clerk: one pass, appending and stamping

Read `briefs/standing-brief-block.md` first, then `/usr/local/src/aesop/pmf-sage/sage-A-adjudicate.md` under "The card" and "Conduct", then `forms/card.md`, then `2-blacklist/fence-index.md`, then `3-decisions/card-1-who-it-is-for.md`, `3-decisions/card-0-one-offer-or-several.md`, `3-decisions/third-card-1.md` and `3-decisions/third-card-0.md`, and then the fenced files the fence index names in this repository: `viewer.tcl`, the `master` branch's README through `git show master:README.md`, and the session memory notes and sibling-product READMEs at the locations the launch message gives. Nothing else is open to you.

The pass decides nothing; it appends and stamps. On each card, append the Priors line last and nowhere else: one entry per source, the file in backticks (or the note's date and kind where it has no path in this repository), its date, and the value it held as a number, a range, or the word it used, for the parameter that card rules and for no other. The program's source holds a present practice (one program, free, read-only, one window); the memory notes hold a stated purpose and a design agreement; the old branch holds the placeholder name's origin; the sibling READMEs hold a related product's scope and price. Quote the word, not a sentence about the recommendation.

Then stamp the Held line by the stated rule: a recommendation matches a prior when it falls inside the prior's stated range or says what the prior says in whatever words; keeps, leaves, held (where a value is held and the recommended line is withheld), or nothing held. Stamp the Chip from the two derivations by the method's rule: where the first derivation and the third agree, on the held value or away from it, the chip reads derived and the card carries both citations; where they differ, the card holds two readings and the chip says so. Fill the Third derivation line on each card with the file and where it landed.

Write `3-decisions/priors-pass.md`: one row per card, what each closed file held for its parameter, and the stamps you gave. Your final message is that table.
